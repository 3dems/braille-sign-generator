# Braille Tactile Sign Generator for PrusaSlicer

Official PrusaSlicer 3.0+ plugin developed by **3DEMS** to generate accessible, standardized tactile Braille signs and plates with optional human-readable visual text and mounting holes.

## Features
- **Standard Braille Dimensions**: Complies with the Marburg Medium standard for signage Braille (dot diameter ~1.5 mm, dot spacing 2.5 mm, cell pitch 6.0 mm).
- **Zero-CAD Generation**: Generates complete ready-to-slice 3D models directly on the build plate.
- **Multilingual Support**: Supports letters A-Z, numbers with automatic number signs, and special Spanish characters (`á`, `é`, `í`, `ó`, `ú`, `ü`, `ñ`, punctuation).
- **Optional Visual Alphabet**: Embosses the text underneath for sighted reading (perfect for dual-color printing).
- **Optional M3 Screw Holes**: Automatically cuts 3.2 mm mounting holes with negative volumes.
