# Braille Tactile Sign Generator for PrusaSlicer

Official PrusaSlicer 3.0+ plugin developed by **3DEMS** to generate accessible, standardized tactile Braille signs and plates with optional human-readable visual text and mounting holes.

## Features
- **Official Signage Standards**:
  - **Europa / España (ONCE - Marburg Medium)**: Dot diameter 1.6 mm, height 0.7 mm, spacing 2.5 mm, cell pitch 6.2 mm.
  - **América / EE.UU. (ADA Standard)**: Visual-to-tactile gap of 9.5 mm (3/8 in) compliant with federal accessibility guidelines.
  - **Internacional / Compacto (BANA)**: Compact cell pitch for space-constrained labeling.
- **100% Reliable Slicing**: Engineered with an integrated anti-thin-wall base stem beneath spherical tactile domes, ensuring 0.4 mm nozzles slice every single dot reliably without thinning or omission.
- **Zero-CAD Generation**: Generates complete ready-to-slice 3D models directly on the build plate in milliseconds.
- **Multilingual Support**: Supports letters A-Z, numbers with automatic Braille number prefix (#), and full Spanish characters (`á`, `é`, `í`, `ó`, `ú`, `ü`, `ñ`, punctuation).
- **Embossed Visual Text**: High-definition embossed text underneath for dual-color or filament change prints.
- **Optional M3 Screw Holes**: Integrated 3.2 mm mounting holes for screw fastening.
